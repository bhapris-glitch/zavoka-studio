# Zavoka Studio (v2.4.0)

Verified zero TypeScript and Vercel build errors.

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Create production build
npm run build
```

## Architecture
- React 18 + Vite SWC engine
- Tailwind CSS responsive obsidian workspace
- Multi-component studio workflow (Editor, Staging, Export Lab)
